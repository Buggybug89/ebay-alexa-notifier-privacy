# Datenschutzerklärung – eBay Alexa Notifier

**Stand: Oktober 2026**

## 1. Zweck der Anwendung
eBay Alexa Notifier ist eine private Testanwendung. Sie soll bezahlte eBay-Bestellungen erkennen und daraus eine akustische Benachrichtigung auf einem Amazon-Echo-Gerät auslösen.

Die Anwendung befindet sich derzeit in der Entwicklungs- und Sandbox-Testphase.

## 2. Verarbeitete Daten
Je nach Ausbaustufe können ausschließlich die für die Benachrichtigungsfunktion notwendigen eBay-Daten verarbeitet werden, insbesondere:

- eBay-Bestell- bzw. Order-ID,
- Benachrichtigungs-ID,
- Bestell- und Zahlungsstatus,
- Anzahl der verkauften Artikel,
- optional der Gesamtbetrag der Bestellung,
- technische OAuth-Zugangsdaten zur Verbindung mit eBay.

Individuelle Kartennamen oder andere für die Benachrichtigung nicht benötigte Inhalte sind für die Grundfunktion nicht vorgesehen.

## 3. Zweck der Verarbeitung
Die Daten werden ausschließlich verwendet, um:

- eine neue bezahlte eBay-Bestellung zu erkennen,
- doppelte Benachrichtigungen zu vermeiden,
- eine akustische bzw. gesprochene Benachrichtigung auszulösen,
- die technische Funktion der Anwendung sicherzustellen.

Eine Nutzung zu Werbezwecken, Profilbildung oder zum Verkauf von Daten findet nicht statt.

## 4. Technische Dienste
Für die spätere Produktivfunktion können technische Dienste wie eBay, Cloudflare sowie ein Dienst zur Alexa-/Echo-Ausgabe eingesetzt werden. Vor einer Produktivnutzung wird diese Datenschutzerklärung an die tatsächlich eingesetzten Dienste angepasst.

In der aktuellen Testphase werden ausschließlich eBay-Sandbox-Testdaten verwendet.

## 5. Speicherung
Daten werden nur so lange gespeichert, wie dies für die jeweilige Funktion erforderlich ist. Benachrichtigungs- oder Bestell-IDs können kurzfristig gespeichert werden, um Mehrfachmeldungen zu verhindern.

OAuth-Zugangsdaten werden als technische Geheimnisse behandelt und nicht öffentlich veröffentlicht.

## 6. Weitergabe
Es erfolgt keine Weitergabe oder ein Verkauf personenbezogener Daten zu Werbe- oder Marketingzwecken. Daten werden nur an technische Dienste übermittelt, soweit dies für die Funktion der Anwendung erforderlich ist.

## 7. Widerruf des eBay-Zugriffs
Ein erteilter eBay-Zugriff kann über die eBay-Kontoeinstellungen für verbundene Anwendungen bzw. Drittanbieter-Zugriffe widerrufen werden.
